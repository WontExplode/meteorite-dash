# meteorite-dash

A small PyGame-CE based game about dodging incoming meteorites, shooting debris and attacking enemies.

## Entwicklung

```terminal
uv sync
uv run meteorite-dash
```

## Checks

```terminal
uv run ruff check .
uv run ruff format .
uv run pytest
uv run mypy
```

# Dev Setup

pre-commit einrichten:

```terminal
git config core.hooksPath .githooks
```
